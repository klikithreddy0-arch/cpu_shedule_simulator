Aim

To implement and compare CPU scheduling algorithms—FCFS, non-preemptive SJF, Round Robin and a simplified Multi-Level Feedback Queue—and calculate completion time, turnaround time and waiting time.

Theory

  • Arrival Time (AT): Time at which a process enters the ready queue.
  • Burst Time (BT): CPU time required by a process.
  • Completion Time (CT): Time at which the process finishes.
  • Turnaround Time (TAT): CT − AT.
  • Waiting Time (WT): TAT − BT.

FCFS runs in arrival order. SJF selects the shortest available job. Round Robin gives each ready process a fixed time quantum. MLFQ uses multiple priority queues and moves unfinished jobs to lower-priority queues.

FCFS

Sort processes by arrival time. time = 0 For each process: If time < arrival, set time = arrival start = time time = time + burst completion = time turnaround = completion - arrival waiting = turnaround - burst

SJF (non-preemptive)

time = 0; mark all processes unfinished While unfinished processes remain: Select the arrived unfinished process with the smallest burst time If none is available, move time to next arrival Run selected process until completion Calculate CT, TAT and WT

Round Robin

Put arrived processes in ready queue While unfinished processes remain: Take first process from queue Run it for min(quantum, remaining burst) Add newly arrived processes to queue If process remains, add it to queue tail Otherwise record completion time

C program — FCFS scheduling

This compact lab-ready C program implements FCFS and prints CT, TAT and WT. The browser simulator above also demonstrates SJF, RR and MLFQ.

#include <stdio.h> struct Process { int pid, at, bt, ct, tat, wt; }; int main() { struct Process p[20], temp; int n, i, j, time = 0; float totalWT = 0, totalTAT = 0; printf("Enter number of processes: "); scanf("%d", &n); for (i = 0; i < n; i++) { p[i].pid = i + 1; printf("Enter arrival and burst time for P%d: ", i + 1); scanf("%d%d", &p[i].at, &p[i].bt); } /* Sort by arrival time */ for (i = 0; i < n - 1; i++) for (j = i + 1; j < n; j++) if (p[i].at > p[j].at) { temp = p[i]; p[i] = p[j]; p[j] = temp; } for (i = 0; i < n; i++) { if (time < p[i].at) time = p[i].at; time += p[i].bt; p[i].ct = time; p[i].tat = p[i].ct - p[i].at; p[i].wt = p[i].tat - p[i].bt; totalWT += p[i].wt; totalTAT += p[i].tat; } printf("\\nPID\\tAT\\tBT\\tCT\\tTAT\\tWT\\n"); for (i = 0; i < n; i++) printf("P%d\\t%d\\t%d\\t%d\\t%d\\t%d\\n", p[i].pid, p[i].at, p[i].bt, p[i].ct, p[i].tat, p[i].wt); printf("Average TAT = %.2f\\n", totalTAT / n); printf("Average WT = %.2f\\n", totalWT / n); return 0; }

1. Which algorithm is simplest?

FCFS is simplest because processes execute in arrival order.

2. Which algorithm can cause starvation?

SJF may starve long processes if shorter processes keep arriving. Priority-based queues can also cause starvation without suitable aging.

3. What is a time quantum?

It is the maximum CPU time given to a process in one Round Robin turn.

4. Can waiting time be negative?

No. With valid scheduling, waiting time is turnaround time minus burst time and cannot be negative.

5. What is the difference between preemptive and non-preemptive scheduling?

In preemptive scheduling, the OS can take the CPU away from a running process. In non-preemptive scheduling, a process keeps the CPU until it finishes or blocks.

6. What does the Gantt chart show?

It shows which process uses the CPU during each time interval.
